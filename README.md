Acest program definește două clase: Wallet și User.

Clasa Wallet reprezintă un portofel digital care poate stoca bani, permite adăugarea de fonduri și retragerea acestora.

Clasa User reprezintă un utilizator care are un nume și un portofel asociat (Wallet).

Programul demonstrează cum se creează obiecte, cum se adaugă și se scad bani din portofel și cum se accesează informațiile unui utilizator.
